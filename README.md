# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？

リモートはgithub上のチーム全体がアクセスできるリポジトリ。
ローカルは自身のPCの中で自身のみがアクセスできるリポジトリ。

## プッシュとマージの違いは何でしょうか？

プッシュはローカルからリモートへのアップロード。
マージは作業ブランチからメインブランチへの統合。

## コミットとプッシュの違い

コミットはローカルリポジトリ内での作業を保存しておくもの。
プッシュはコミットしておいた作業内容をリモートにアップするもの。

## コミットのメッセージはどのように書いてあげるのが最適でしょうか？

どのような作業を行なったかコミットか
自分だけでなく他の作業者が見たときにも一目でわかるように書く。

## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？

ローカルでマージするフローは、
第三者のレビューを通さずにマージすることができるため、
素早い更新作業ができる反面、バグ等の発生リスクが高まる。

PRでマージするフローは、
第三者のレビューを通してからマージするため、
時間はかかるがバグ等の発生リスクを最小限に抑えることができる。

## コンフリクトを起こしてしまった場合、どう対処すべきですか？

Aの修正内容だけを反映するか、Bの修正内容だけを反映するか、
どちらの修正内容も反映するかの3択の中から適切な方法で対処する。
